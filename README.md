# OnlineStore — Sistema Web de Tienda Online

## Descripción del proyecto

OnlineStore es un proyecto integrador desarrollado en el ámbito de la carrera Analista de Sistemas de Computación del IPET N.º 1308.

El objetivo es desarrollar un sistema web de tienda online que permita organizar y gestionar productos, compras y pedidos mediante una interfaz accesible y ordenada.

## Objetivos

- Organizar la información de los productos.
- Facilitar la consulta del catálogo.
- Representar el proceso de compra y la gestión de pedidos.
- Aplicar conocimientos de programación, bases de datos y desarrollo web.
- Documentar el proceso de análisis, diseño e implementación del sistema.

## Tecnologías

El proyecto contempla tecnologías de desarrollo web como PHP, HTML, CSS, JavaScript y MySQL. La implementación concreta debe verificarse con los archivos del proyecto.

## Estructura del repositorio

- `documentacion/`: documentación formal del proyecto.
- `codigo/`: espacio destinado al código fuente.
- `base-de-datos/`: espacio destinado a los scripts y archivos de la base de datos.
